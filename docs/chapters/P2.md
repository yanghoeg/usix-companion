- Implement the shared v2 device contract in the APK and an installable Companion-owned host CLI/broker: negotiation, authenticated pairing, outbound WSS, one controller lease, typed failures, durable action receipts and event outbox.
- Preserve supported v1 response/authentication/package behavior through the same application ports. Legacy calls cannot claim durable deduplication or verified completion.

## Implementation and required checks

1. Capture current runtime source/binary and physical-device readiness; determine APK update and genuine model invocation paths.
2. Extend pure domain/application ports with execution identity, injected time/IDs, sessions/controller, journal and bounded events. Validate immutable bindings and serialize effects.
3. Implement strict shared-wire mapping and golden/failure conformance against the existing schemas; publish explicit supported/readiness capability states.
4. Add relational durable journal/outbox and startup recovery: record before dispatch, return identical receipts, reject conflicting action IDs, preserve uncertain effects, cancellation and event gaps.
5. Add local pairing/revocation and secure phone-initiated WSS with authenticated expiry/replay protection; expose local controls and keep the HTTP listener on loopback.
6. Package bounded structured host CLI/broker and setup/skill instructions independent of checkout/cwd. Bind trusted context outside model arguments and keep credentials out of output.
7. Run core/architecture, protocol, persistence migration/recovery, loopback/WSS, controller/race and CLI tests; build/lint/sign APK.
8. Install/update the physical-device APK and validate local/remote calls, controller conflict, payload conflict, lost acknowledgement/restart and persisted receipts/events. Run genuine model→existing authorized tool→device evaluation on both pinned unchanged runtimes; distinguish direct calls from model evidence.
9. On all exits passing, write permanent P2 evidence and plan handoff, update references, then delete this temporary execution document. If required evidence is missing, preserve this document and report the specific remaining gate.
